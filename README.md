GameView é um site de avaliação de jogos onde você faz a pesquisa de um certo jogo e da uma 
nota de 0 a 100 para a história, gráficos, jogabilidade e performance, além de um texto com sua opinião.
Também é possível que outros usuários avaliem positivamente ou nagativamente o sua avaliação.

Este projeto foi um dos requisitos para a conclusão do curso técnico em Desenvolvimento de Sistemas na ETEC Philadelpho Gouvêa Netto.

Front-end: HTML5, CSS3 e Bootstrap
Back-end: PHP e JavaScript
Banco de Dados: MySQL

Requisitos para execução: XAMPP
