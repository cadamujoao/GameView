GameView é um site de avaliação de jogos onde você faz a pesquisa de um certo jogo e da uma 
nota de 0 a 100 para a história, gráficos, jogabilidade e performance, além de um texto com sua opinião.
Também é possível que outros usuários avaliem positivamente ou nagativamente o sua avaliação.

A API utilizada não oferece nenhuma informação necessária para filtrar quais jogos seriam exibidos, por esse motivo os jogos só aparecerão
quando houver ao menos uma avaliação ou se você pesquisar.

Este projeto foi um dos requisitos para a conclusão do curso técnico em Desenvolvimento de Sistemas na ETEC Philadelpho Gouvêa Netto.

Front-end: HTML5, CSS3 e Bootstrap
Back-end: PHP e JavaScript
Banco de Dados: MySQL

Requisitos para execução: XAMPP e conexão a internet

Banco de Dados:
1. Abra o painel de controle do XAMPP e inicie os módulos **Apache** e **MySQL**.
2. No seu navegador, acesse: 'http://localhost/phpmyadmin/' ou clicando no botão 'Admin' do módulo **MySQL**
3. Clique no cabeçalho acima em **"SQL"** e cole o conteúdo do arquivo 'GameView.sql', e clique em **"Go"** para criar o banco de dados

Site:
1. Após baixar e extrair o arquivo .zip, copie a pasta **"GameView-X.0"**
2. Acesse C:\xampp\htdocs e cole a pasta, renomeie a pasta para **"gameview"**
3. Acesse o site pelo navegador "localhost/gameview"
